# Contributing

Thank you for your interest in contributing!

## 🌱 This Repo Is a Derived Scraper

This scraper was derived from the [EPAM Systems International SRL template](https://github.com/sebiboga/epam-systems-international-srl-nodejs-scraper). All company-specific configuration lives in `scraper/config/company.json`.

For instructions on how to derive a new scraper, please refer to the [EPAM template](https://github.com/sebiboga/epam-systems-international-srl-nodejs-scraper).

## Development Setup

```bash
npm install
npm test
```

## Reporting Issues

Open a [GitHub Issue](https://github.com/peviitor-scrapers/utilben-srl-nodejs-scraper/issues) with:
- Clear description of the problem
- Steps to reproduce
- Expected vs actual behavior
